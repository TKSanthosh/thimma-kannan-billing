# திம்ம கண்ணன் - மொபைல் பில்லிங் செயலி (Thimma Kannan Billing PWA)

ஒரு எளிய, அதிவேக மொபைல் பில்லிங் செயலி (Mobile-First POS Progressive Web App) தமிழ்நாட்டில் உள்ள பூஜை பொருட்கள் மற்றும் மளிகை கடைக்காக உருவாக்கப்பட்டது.

## முக்கிய சிறப்பம்சங்கள் (Key Features)

1. **முழுமையான தமிழ் இடைமுகம் (Pure Tamil UI)**:
   - தாய்மார்கள் மற்றும் கணினி அறிவில்லாத எளிய நபர்களும் மிக எளிதாக பயன்படுத்தும் வகையில் வடிவமைக்கப்பட்டுள்ளது.
   - பெரிய பொத்தான்கள் (Large touch buttons), எளிய எழுத்துக்கள், தெளிவான வண்ணங்கள்.

2. **ஆங்கில தட்டச்சு மூலம் தமிழ் தேடல் (English Transliteration → Tamil Search)**:
   - பயனர் தமிழ் தட்டச்சு செய்ய வேண்டியதில்லை. ஆங்கில எழுத்துக்களிலேயே தட்டச்சு செய்யலாம்.
   - உதாரணம்:
     - `k` அல்லது `ku` -> **குங்குமம்**, **குடம்**, **கற்பூரம்**, **குத்துவிளக்கு**
     - `kung` -> **குங்குமம்** (முதலிடத்தில் பரிந்துரைக்கப்படும்)
     - `man` -> **மஞ்சள்**, **மஞ்சள் பொடி**
     - `kar` -> **கற்பூரம்**
     - `sam` -> **சாம்பிராணி**
     - `ooth` -> **ஊதுபத்தி**

3. **தொடர்ச்சியான பில்லிங் பணிப்பாய்வு (Continuous Billing Workflow)**:
   - ஒரு பொருளை தேர்ந்தெடுத்தவுடன், அடுத்த வரிசை தானாகவே உருவாகும்.
   - அளவு அதிகரிக்க பெரிய `[ − ]` மற்றும் `[ + ]` பொத்தான்கள்.
   - தேவைப்பட்டால் ஒரு குறிப்பிட்ட பில்லுக்கு மட்டும் பொருளின் விலையை மாற்றிக்கொள்ளும் வசதி.
   - ஒரு பொருள் நீக்கப்பட்டால் உடனடியாக மொத்தம் மாறும்.

4. **பணம் செலுத்துதல் & ரசீது (Payment & Receipt)**:
   - பணம் (Cash) மற்றும் UPI (GPay / PhonePe) ஆதரவு.
   - பெறப்பட்ட பணத்திற்கான மீதம் (Change calculation) கணக்கீடு.
   - தொடர் பில் எண்கள் (Sequential bill numbering: `#1001`, `#1002`...).
   - ரசீதை WhatsApp வழியே பகிரும் வசதி மற்றும் அச்சிடும் வசதி (Print support).

5. **இணையம் தேவையில்லை (Offline-First IndexedDB)**:
   - இணைய இணைப்பு இல்லாத போதும் பில்லிங் முழுமையாக வேலை செய்யும்.
   - உங்கள் மொபைலிலேயே பில் தரவுகள் பாதுகாப்பாக சேமிக்கப்படும்.
   - தரவு ஏற்றுமதி & மீட்டமைத்தல் (JSON Backup & Restore) வசதி.

6. **PWA & GitHub Pages Hosting**:
   - Android Chrome-ல் இருந்து செயலியை மொபைலில் "Install" செய்து பயன்படுத்தலாம்.
   - GitHub Pages-ல் நேரடியாக ஹோஸ்ட் செய்யும் வகையில் உருவாக்கப்பட்டுள்ளது.

## தொழில்நுட்பம் (Tech Stack)

- **React 18 + TypeScript**
- **Vite 6 + Tailwind CSS**
- **Vite PWA Plugin (Offline Service Worker)**
- **Dexie.js (IndexedDB)**
- **Lucide Icons**
